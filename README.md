# portfolio-v2

Justin Joseph's personal portfolio. Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build + type-check
npm run lint
```

## Where things live

- `lib/site.ts`: name, tagline, location, email, nav and social links
- `lib/content.ts`: about, stats, projects, experience, tools
- `app/globals.css`: colour and font tokens
- `components/ui/`: reusable pieces (Button, Section, LinkRow, Field, Icons…)
- `components/sections/`: page sections
- `components/layout/`: header, menu, footer
